2) What data the App may receive

When connected to Instagram/Meta services, the App may receive and process the following data as required for functionality:

technical identifiers and event metadata (e.g., account IDs, message IDs, timestamps);

access tokens and related authorization information needed to access APIs.

3) How the data is used

The App uses the data only to:

receive and handle webhook events;

send/receive messages via the API (if enabled);

maintain stability, troubleshoot issues, and secure the integration.

4) Data storage and retention

The App is designed for personal use and, by default:

does not sell data;

does not share data with third parties except as necessary to use Instagram/Meta services;

does not permanently store message content (unless you explicitly enable such a feature);

may process data temporarily in memory to perform requested actions.

Technical logs may include minimal information necessary for diagnostics (such as request time and response status). Any additional logging can be disabled by the operator.

5) Data sharing

The App does not disclose personal data to third parties, except:

to Meta/Instagram as part of normal API/webhook operations; or

if required by applicable law.

6) Security

Reasonable security measures are used to protect the integration, including access control and the use of HTTPS for public endpoints.

7) Data deletion

Because the App is used only by the account owner, data deletion can be performed by:

revoking the App’s access in Meta/Instagram account settings (disconnect/remove the App); and/or

deleting locally stored configuration and tokens on the server where the App runs.
