# Form90

Мобильный трекер 16-недельной программы Full Body A/B/C: 3 тренировки в неделю по 60 минут.

## Возможности

- программа на 16 недель с фазами и разгрузочными неделями;
- тренировки A/B/C;
- запись рабочего веса, повторений и RIR для каждого подхода;
- учёт собственного и дополнительного веса в подтягиваниях/брусьях;
- таймер тренировки на 60 минут и таймер отдыха;
- история тренировок;
- графики веса и талии;
- рабочие рекорды;
- локальное хранение в IndexedDB;
- JSON/CSV экспорт и JSON импорт;
- PWA и офлайн-режим после первого запуска;
- мобильный интерфейс + десктопная боковая навигация.

## Локальный запуск

Проект не требует сборки.

```bash
python3 -m http.server 8080
```

Откройте `http://localhost:8080`.

> Service Worker не работает через `file://`, поэтому для локальной разработки нужен HTTP-сервер.

## GitHub Pages

Репозиторий `PavelKuchkovskii/pavelkuchkovskii.github.io` публикуется как пользовательский GitHub Pages сайт. Файлы приложения находятся в корне репозитория.

При публикации через GitHub Actions используется `.github/workflows/pages.yml`.

## Данные

Тренировки и измерения хранятся только в IndexedDB браузера. Серверная база данных отсутствует. Перед сменой устройства используйте **Настройки → JSON** для резервной копии.

## Структура

- `index.html` — оболочка приложения;
- `styles.css` — адаптивный GPT-light визуальный стиль;
- `app.js` — программа, IndexedDB, тренировки, история, прогресс;
- `manifest.webmanifest` — PWA;
- `sw.js` — офлайн-кэш;
- `.github/workflows/pages.yml` — автоматическая публикация.
